# Cross-Chapter Relations

This directory contains cross-reference and relation data between documentation chapters.

## Files

- **relations.csv** - Cross-chapter facet links and dependencies

## Format

```csv
from_facet,to_facet,source_file
```

Currently contains facet-to-facet links extracted from documentation.

## Usage

Use this data to:
- Visualize documentation graph
- Find related chapters
- Validate link integrity
- Generate navigation aids
