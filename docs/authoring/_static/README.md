# Authoring _static

Ten katalog jest zarezerwowany na zasoby wspierające dokumentację (np. miniatury, zrzuty, pliki pomocnicze).
**Nie wymaga** zmian w `conf.py` – na razie pełni rolę bufora dla Agenta (może tu składać artefakty do późniejszej integracji).

Wskazówki:
- Obrazy umieszczaj w podkatalogu `_static/images/` i linkuj względnie z rozdziałów authoring.
