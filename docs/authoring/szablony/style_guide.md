# Style guide (pisanie dokumentacji)

- Używaj nagłówków H2/H3/H4 i kotwice MyST `(anchor)=`.
- Krótkie akapity, listy, tabele, admonitions.
- Kod w blokach z językiem: ```lua, ```cpp itd.
- Linki wewnętrzne: `{doc}` i kotwice.

:::{tip}
PyData + Sphinx Design oferują **cards/grids/tabs** do budowy ładnych stron.
:::
