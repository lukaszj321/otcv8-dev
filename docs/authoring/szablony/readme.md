# Szablon README

:::{admonition} Jak używać?
Skopiuj sekcje do `README.md` w projekcie i uzupełnij.
:::

## Proponowana struktura

- Nazwa i opis projektu (1–2 zdania).
- Badges (CI, PyPI/NPM, License) – opcjonalnie.
- Instalacja / Wymagania.
- Szybki start (krótki przykład).
- Dokumentacja (link do /docs).
- Contributing / Code of Conduct / Security.
- Licencja.

### Szkielet

```md
# NAZWA PROJEKTU

Krótki opis projektu.

## Instalacja
…

## Szybki start
…

## Dokumentacja
- Strona główna: <URL>
- API: <URL>

## Security
Patrz: SECURITY.md

```
