
# OTUI Templates Collection

Repozytorium *kanonicznych* szablonów OTUI do szybkiego użycia i przeglądu stylów.

## Struktura
- `widgets/<widget_id>.otui` — surowy szablon
- `diagrams/<widget_id>.mmd` — diagram relacji i hierarchii (Mermaid)
- `index.md` — spis i podgląd

## Wymagania
- Każdy diagram ma mieć `%%{init: { 'theme': 'dark' }}%%`
- Każdy element w diagramie powinien linkować do odpowiedniej kotwicy `(facet-...)`
