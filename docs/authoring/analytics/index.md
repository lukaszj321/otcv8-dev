# Analytics Overview

This directory contains comprehensive analytics and coverage reports for the OTClient v8 documentation rebuild.

## Files

- **coverage.csv** - Per-chapter statistics (size, datasets, diagrams, status)
- **gaps.md** - Identified gaps and actionable steps for improvement
- **xref_stats.csv** - Cross-reference statistics between chapters
- **run_summary.json** - Overall summary of the documentation rebuild
- **errors.md** - Detailed error log and GAP documentation
