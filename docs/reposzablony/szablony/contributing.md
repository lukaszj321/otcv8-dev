# Contributing (wkład w projekt)

:::{admonition} Zasady
- Używaj branchy tematycznych: `feat/…`, `fix/…`.
- Commity: `type(scope): opis` (konwencja *Conventional Commits*).
- PR: krótki opis + checklist.
:::

## Jak zacząć
1. Fork/Branch.
2. Uruchom testy/linty lokalnie.
3. Dodaj opis w PR.

## Szablon PR (propozycja)

```md
### Opis
…

### Zmiany
- [ ] …

### Testy
…
```
